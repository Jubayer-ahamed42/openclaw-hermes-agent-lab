# AGENTS.md - Operational Rules for Nous Hermes

## Working Environment
- All file operations and scripts must be kept inside the active workspace (`./workspace`).
- Python scripts should be written using Python 3 and executed via `python <script_name>.py`.
- Windows PowerShell / CMD commands can be executed using the `exec` tool.
- When creating code artifacts, prefer clean, modular, self-contained implementations.
